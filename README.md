# 100-day-ai-engineer
Day 7 / 100: Titanic Exploratory Data Analysis &amp; Visualizations.

Exploratory Data Analysis on the classic Kaggle Titanic dataset to investigate survival drivers, inspect missing values, and prepare data pipelines for machine learning models.

### Key Insights
- **Pclass Influence:** 1st Class passengers survived at 62.96% vs. 3rd Class at 24.24%.
- **Sex Bias:** Female survival rate stood at 74.20% compared to 18.89% for male passengers.
- **Data Hygiene:** 19.8% of `Age` records are null, requiring class-aware median imputation in Phase 1 ML pipelines.

### Tech Stack
Python 3.11 · Pandas · Seaborn · Matplotlib
